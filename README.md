## Overview
DocMind AI is a Retrieval-Augmented Generation (RAG) system that lets users upload any PDF and query its contents using natural language. Rather than summarizing blindly, it retrieves the most semantically relevant chunks and generates answers grounded strictly in the document, with source references for full transparency.

---

## Features
- Upload any PDF and start querying within seconds
- Semantic chunk retrieval using FAISS vector search
- Answers generated by LLaMA 3.3 70B via Groq, fast and accurate
- Source chunks surfaced alongside every answer for auditability
- Fully local embeddings, no external embedding API dependency

---

## Tech Stack
| Layer | Technology |
|---|---|
| LLM | Groq, LLaMA 3.3 70B |
| RAG Orchestration | LangChain |
| Vector Store | FAISS |
| Embeddings | HuggingFace `all-MiniLM-L6-v2` |
| PDF Parsing | PyMuPDF |
| Frontend | Streamlit |
| Deployment | Streamlit Community Cloud |
